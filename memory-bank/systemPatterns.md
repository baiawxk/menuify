# 系统模式

## 系统架构
```
核心组件
├── 配置管理
│   ├── 配置加载 (unconfig)
│   └── 环境变量处理
├── 执行器系统
│   ├── 基础执行器
│   │   ├── Execa执行器 (命令执行)
│   │   ├── Open执行器 (链接打开)
│   │   └── Function执行器 (自定义函数)
│   └── 扩展执行器
│       ├── Listr2执行器 (原生任务列表)
│       └── Concurrently执行器 (原生并行任务)
├── 用户界面
│   └── CLI交互
```

## 关键技术决策
1. 执行器分类
   - 基础执行器：保留环境变量和输入处理
   - 扩展执行器：直接使用原生配置

2. 类型系统策略
   - 导入原生类型定义
   - 最小化类型包装
   - 保持类型安全

## 设计模式
1. 适配器模式
   - 仅用于基础执行器
   - 扩展执行器直接转发

2. 代理模式
   - 简单包装原生功能
   - 保持接口一致性

## 组件关系
1. 配置加载 -> 执行器选择 -> 任务执行
2. 用户输入 -> 配置处理 -> 执行器初始化
3. 执行器 -> 原生库调用 -> 结果处理

## 关键实现路径
1. 执行器处理流程
   ```
   配置解析 -> 执行器选择 -> 配置转换 -> 原生执行
   ```

2. 并行任务处理
   ```
   任务分组 -> 并行配置 -> concurrently执行 -> 结果聚合
   ```

3. 任务列表处理
   ```
   任务定义 -> listr2配置 -> 任务执行 -> 进度展示
   ```
