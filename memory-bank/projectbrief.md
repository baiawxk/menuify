# CLI Menu (menuify) - 项目简介

## 项目目标
创建一个受VSCode Tasks启发的CLI菜单生成器，为终端工作流提供类似的便利性。

## 核心需求
1. 为开发者提供友好的交互式CLI菜单
2. 简化重复性命令的执行
3. 标准化团队开发工作流程
4. 支持跨平台环境变量配置

## 主要功能范围
- 交互式CLI菜单，支持模糊搜索
- 自动配置加载（通过unconfig）
- 执行命令、打开链接或运行自定义函数
- 丰富的输入类型支持
- 任务依赖关系和执行模式
- 跨平台环境变量支持
- VSCode风格的任务配置体验

## 目标用户
- 需要频繁在项目间切换的开发者
- 需要为不同环境配置不同参数组合的团队
- 希望与团队共享标准化开发工作流程的开发者

## 项目范围界定
### 包含
- CLI菜单生成和管理
- 配置文件处理
- 任务系统实现
- 环境变量处理
- 输入类型支持

### 不包含
- GUI界面
- 远程任务执行
- 实时任务监控
