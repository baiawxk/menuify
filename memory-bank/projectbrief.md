# CLI Menu 项目简报
## 项目名称
CLI Menu 工具库

## 核心目标
开发一个用于构建交互式命令行菜单的TypeScript工具库，支持变量解析、多类型菜单项（命令、链接、函数）执行等功能，提升命令行工具的用户交互体验。

## 范围
- 变量解析器（EnvResolver）实现
- 菜单项执行处理器（TaskHandler）
- 交互式输入适配器（Inquirer等）
- 测试覆盖率达到90%以上
- 支持pnpm包管理和TypeScript类型检查

## 关键成功因素
- 灵活的变量作用域解析（输入>菜单>全局）
- 稳定的命令/函数执行上下文管理
- 良好的类型定义（使用type-fest）
- 符合POSIX标准的跨平台兼容性
