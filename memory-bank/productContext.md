# 产品上下文

## 为什么存在
menuify的存在是为了解决开发者在日常工作中面临的以下问题：
1. 需要在不同项目间切换时重复输入复杂命令
2. 需要为不同环境配置不同的参数组合
3. 需要与团队分享标准化的开发工作流程

## 问题解决方案
通过提供VSCode Tasks风格的CLI菜单系统：
- 简化命令执行流程
- 统一团队工作流程
- 提供跨平台支持
- 实现任务依赖管理

## 工作方式
1. 配置加载
   - 支持TypeScript/JavaScript/JSON配置文件
   - 通过unconfig自动加载配置

2. 菜单项类型
   - 命令菜单：执行shell命令
   - 链接菜单：打开URL或文件
   - 函数菜单：执行自定义函数

3. 用户输入处理
   - 文本输入(promptString)
   - 单选(pickString)
   - 确认(confirm)
   - 多选(multiSelect)

4. 任务系统
   - 支持任务依赖
   - 串行/并行执行模式
   - 自定义函数支持

## 用户体验目标
1. 简单易用
   - 友好的交互式菜单
   - 支持模糊搜索
   - 清晰的命令行选项

2. 灵活配置
   - 多种配置文件格式
   - 丰富的输入类型
   - 环境变量支持

3. 开发效率
   - 快速切换任务
   - 标准化工作流
   - 减少重复工作
